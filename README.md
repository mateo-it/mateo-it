### About me

I've been building web products professionally since 2018: SaaS dashboards, project-management and compliance tools, lead-generation platforms, CMSs, webshops and the APIs behind them. On the frontend I mostly work in **React, Next.js and TypeScript**; on the backend in **Laravel, Symfony and Django**. I've worked with clients and teams in the United States, Germany, France, Armenia and Croatia.

In 2023 I founded **CodeVerse d.o.o.** in Pregrada, Croatia. We build websites, webshops and web apps, and we automate document processing, search and workflows for US healthcare companies.

- **Frontend:** typed React and Vue apps, with component libraries built in shadcn/ui and documented in Storybook
- **Backend:** REST and GraphQL APIs, payments with Stripe, and search with Meilisearch
- **AI-assisted development:** Claude Code, Codex and Cursor are part of my daily workflow
